🎧 SHATY⨕2090

**Um player de música para desktop, desenvolvido com Electron, HTML, CSS e JavaScript.**

O SHATY⨕2090 é um projeto independente que busca unir desenvolvimento de software, nostalgia, identidade visual e experimentação tecnológica em uma aplicação desktop.

✨ Sobre o projeto

O objetivo é desenvolver um player de música com interface personalizada, visual moderno e foco na simplicidade de uso.

Este projeto também faz parte da minha jornada de aprendizado em programação, explorando novas tecnologias e transformando ideias em aplicações reais por meio do *vibe coding* e do desenvolvimento assistido por inteligência artificial.

 🛠️ Tecnologias utilizadas

- **Electron** — desenvolvimento de aplicações desktop.
- **HTML5** — estrutura da interface.
- **CSS3** — estilização e identidade visual.
- **JavaScript** — lógica e funcionalidades da aplicação.

🚀 Como executar

 Pré-requisitos

- [Node.js](https://nodejs.org/)
- npm, incluído na instalação do Node.js.

### Instalação

1. Clone este repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd SEU-REPOSITORIO
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```


4. Execute o comando de inicialização configurado no arquivo `package.json`.

   ou se já tiver tudo certo, simplismente abra o projeto em seu vs code :)

   no terminal do vs code na pasta do projeto envie : npm start
